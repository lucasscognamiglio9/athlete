# Session Coaching

Make the current session easy to execute without silently redesigning the plan.

Read [`../../shared/coach-core.md`](../../shared/coach-core.md) and [`../../shared/canonical-file.md`](../../shared/canonical-file.md) completely before acting. Read [`../../shared/evidence-protocol.md`](../../shared/evidence-protocol.md) when a consequential or materially uncertain live decision can change the recommendation.

## 1. Resolve today's session

Read the active plan version, session order, relevant recent sessions, and any active decision that changes execution. Use the athlete's date or stated session; clarify only when two plausible sessions would produce different guidance.

Continue when the exact canonical session or the provisional nature of the guidance is explicit.

## 2. Present the execution view

Show the work in training order with the values the athlete needs now: task, dose, target effort or intensity, relevant rest or setup, and the active progression or adjustment boundary. Omit fields that do not affect execution.

Continue when the athlete can start without translating the plan themselves.

## 3. Coach the live decision

During training, combine the verified plan with the athlete's current report. Give the smallest adjustment that preserves the session objective. Distinguish a one-session execution choice from a durable plan change.

A durable change follows `training-design`; completed work follows `training-log`. Keep the current answer focused on the live decision.

## 4. Preserve authority

Do not mutate the plan or session record unless the athlete explicitly requests that change or reports completed work. If canonical access is unavailable, label plan-dependent guidance provisional.

Finish when the athlete knows exactly what to do next and which part, if any, still requires a later record or plan update.
